## Costline v0.2.0

> 相对 `v0.1.0`，本次发布包含未提交的工作区改动。

### 新增功能
- 新增定投提醒：股票、基金、黄金都可以按资产设置每期金额、每周或每月、定投日与提醒时间，到点后通过已配置的通知渠道发送提醒。定投只负责提醒，不会自动下单，也不会修改成本价。
- 定投提醒同一天只发送一次；每月定投日超过当月天数时按当月最后一天处理；暂停盯盘时定投提醒同步暂停。
- 提醒内容包含当期金额、当前价以及按当前价估算的可买数量。
- 添加资产时支持按名称或代码搜索 A 股、港股、美股、ETF、场外基金和黄金，选中结果后自动填入类型、名称与代码。
- 盯盘面板新增「添加持仓」入口，可以直接新增资产，无需先进入设置页。
- 盯盘面板新增「隐藏 / 显示」开关，可一键遮挡成本价、触发价、浮动盈亏和定投金额。
- 设置页的资产与通知渠道改为修改后立即保存并生效，基础参数仍通过底部按钮统一保存。

### 体验优化
- 资产列表会显示定投计划、今日是否到期以及下次定投时间，到期时以高亮样式提示。
- 定投到期时，面板内会弹出提醒卡片，可直接跳转查看。
- 保存资产和通知渠道时显示保存中状态，避免重复提交。
- 命令行版单次检查会输出当日定投提醒及发送结果。

### 问题修复
- 修复 macOS 系统通知未正确初始化、部分情况下无法在通知中心显示的问题。

### 其他变更
- README 补充定投提醒的配置字段、行为说明与示例。
