## Costline v0.3.0

> 相对 `v0.2.0`，本次发布包含未提交的工作区改动。

### 新增功能
- 新增券商交割单导入：支持 CSV / TXT，自动识别常见券商表头、UTF-8 / GBK / GB18030 编码和多种分隔符；配置目录后可自动读取新成交，也可通过命令行单次导入。
- 持仓改为按「期初持仓 + 成交流水」计算：买入增加本金和数量，卖出按成交净额扣减本金；卖出盈利会降低回本线，卖出亏损会提高回本线。
- 当剩余本金 ≤ 0 时标记「本金已收回」，剩余数量为 0 时标记「已清仓」，并自动停止对应的回本提醒。
- 面板增加剩余本金、「本金已收回」「已清仓」状态展示。
- 交割单按文件变化和成交编号去重，重复导入同一文件或同一笔成交不会重复扣减本金；卖出数量超过当前持仓时会拒绝该笔成交并给出提示。
- 新增「实时价格」开关：开启后每 10 秒刷新一次股票、基金和黄金行情，暂停自动盯盘时也能继续查看价格。
- 黄金、黄金基金和黄金股票会同时显示国内金价（上海金 Au99.99，元/克），面板、回本提醒和命令行输出中均可查看。
- 定投提醒前会校验场外基金的申购状态：暂停申购、封闭、低于最小申购金额或超过单笔上限时发送阻断提醒；状态查询失败时提示人工确认。
- 面板展示定投基金的申购状态和单笔上限，阻断时提示本期不买入；定投提醒与命令行输出会标记「阻断」「状态未知」。
- 命令行版新增交割单导入命令，`check` / `watch` 会同时同步交割单；资产表格增加剩余本金、清仓状态和国内金价展示。

### 体验优化
- 设置页新增「交割单目录」，目录和文件路径均支持 `~`。
- 申购状态会缓存：定投日 15 分钟、其他时间 6 小时，减少重复请求；阻断提醒与正常提醒分开记录，状态当天恢复开放后仍会正常提醒。
- 已导入的成交流水保存在本地，不需要每轮重复解析或修改配置文件。
- 禁用 WebView 默认右键菜单，避免误触「刷新」导致界面重载。

### 问题修复
- 修复重置提醒状态时会一并清除已导入交割单记录的问题；现在只清空提醒状态，成交流水会保留。
- 修复资产没有触发价（例如本金已收回或已清仓）时，伪装模式财务表显示异常的问题。

### 其他变更
- 定投目前仍只发送提醒和申购状态判断，不会自动下单，也不会自动把定投期次计入持仓。
