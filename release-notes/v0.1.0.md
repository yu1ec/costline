## Costline v0.1.0

> 首个版本，包含未提交的工作区改动。

### 新增功能

- 新增常驻 macOS 菜单栏的盯盘应用，关闭窗口后仍会在后台持续检查行情。
- 支持 A 股、港股、美股、ETF、场外基金、上海黄金和国际金价。
- 持仓资产支持添加、编辑和删除，成本价可以直接填写，也可以按「本金 ÷ 数量」自动换算。
- 支持全局回本阈值、单个资产独立阈值，以及直接指定目标价。
- 回本提醒仅在价格从下方穿越触发线时触发，并支持提醒冷却时间和价格持续高于触发线时的重复提醒。
- 通知渠道支持 Bark、Server 酱、PushPlus、Telegram、企业微信、钉钉、飞书、ntfy、Gotify 和通用 Webhook。
- 桌面端触发提醒时会始终发送 macOS 系统通知，并在应用窗口内展示；远程渠道可以同时配置。
- 托盘菜单提供打开面板、立即检查、暂停或恢复盯盘以及退出。
- 内置伪装模式，提供开发、运营、产品、财务四种身份，支持数据换皮与全屏伪装，并可设置为启动时自动进入全屏伪装。
- 伪装过程中可按住 `⌥` 临时查看真实资产名称，设置页也提供当前身份与真实资产的对照列表。
- 内置应用内更新，启动时会检查新版本，可在应用内下载、校验签名并重启。
- 提供命令行版本，适合没有图形界面或需要由 launchd 定时运行的场景。
- 配置与提醒状态均保存在本地，无需数据库或云端账号。

### 体验优化

- 面板顶部汇总资产数量、已回本数量和最近检查时间，现价高于触发价的资产会高亮显示。
- 行情表格展示现价、成本、触发价、日涨跌、浮动盈亏和备注等信息。
- 设置页集中管理轮询间隔、请求超时、提醒冷却、持仓资产和通知渠道，并可重置提醒状态或打开配置目录。
- 桌面版首次启动时会自动导入命令行版已有的配置和提醒状态。
